# 配布と初回設定

開発機ではなく、**利用者の PC で動かすための手順**。
「シェルにコマンドを打つ」「環境変数を設定する」「開発者向けのトークンを自分で取る」を
利用者側に残さないことを目標にしてある。

| | 配る人 (エンジニア) | 使う人 |
|---|---|---|
| 用意するもの | Claude の API キー、(任意で) Google の OAuth クライアント、Slack アプリ | 自分の Google / Slack / GitHub アカウント |
| 触るもの | `config\app-config.json`、ZIP | `Install.cmd` とデスクトップのアイコン、カンバンの「接続」 |
| 使うもの | 端末 | ブラウザだけ |

---

## 配る人の手順

### 1. 資格情報を用意する

利用者の権限では取れないものだけを、こちら側で用意する。

| 何 | どこで | 無いとどうなるか |
|---|---|---|
| Claude の API キー | https://console.anthropic.com/settings/keys | **カードが1枚も作られない**（取り込みだけが動く） |
| Google の OAuth クライアント (デスクトップ アプリ) | Google Cloud。Gmail API と Calendar API を有効化 | 利用者が自力で Google Cloud にプロジェクトを作る羽目になる |
| Slack アプリの Bot / User Token | https://api.slack.com/apps | 同上（ワークスペースへの導入権限が要る） |

GitHub のトークンは**個人のもの**なので、ここでは用意しない。利用者が画面から入れる。

### 2. `config\app-config.json` を作る

```powershell
copy config\app-config.sample.json config\app-config.json
```

用意できたものだけを書く。空欄の項目は無視される。

```json
{
  "anthropic": { "apiKey": "sk-ant-..." },
  "google":    { "clientId": "....apps.googleusercontent.com", "clientSecret": "..." },
  "startup":   { "port": 8787, "openBrowser": true }
}
```

- 起動時に **DPAPI の保管庫へ取り込まれる**。取り込んだあとはこのファイルから値を消してよい。
- **すでに保管庫にある項目は上書きしない。** 利用者が画面から入れ直した値が、
  次の起動で配布時の値に戻ることはない。
- このファイルは平文なので `.gitignore` してある。ZIP に同梱する場合は渡し方に注意する。
- Google は「クライアントの ID と秘密」だけを配る。**どのメールボックスを見るかは
  利用者が自分で同意する。**こちらのアカウントには一切触れない。

### 3. フォルダごと渡す

ZIP に固めて渡す。`phase1/data`・`phase2/data`・`phase5/data`・`logs`・`phase4/output` は
入れない（他人の業務データと資格情報が入っている）。

```powershell
# 例: 実データを除いて固める
$ex = @('phase1\data','phase2\data','phase5\data','phase4\output','logs','.git')
```

### 4. 伝えること

> 展開して `Install.cmd` をダブルクリック。あとはデスクトップの「通知コレクター」から。

これ以上は要らない。足りない設定は画面が言う。

## 使う人の手順

1. 受け取ったフォルダを展開する（デスクトップやドキュメントなど、書き込める場所へ）
2. `Install.cmd` をダブルクリックする
   - デスクトップに「通知コレクター」ができる
   - サインイン時の自動起動を聞かれる（後から `Install.cmd` で変えられる）
3. 「通知コレクター」をダブルクリックする
   - ブラウザでカンバンが開く
   - 窓（黒い画面）は**閉じない**。閉じると止まる。最小化しておけばよい
4. まだ接続していないものがあれば、カンバンの右上「接続」から入れる
   - **Claude** … これが無いとカードは作られない。配布時に設定済みなら何もしなくてよい
   - **Gmail / カレンダー** … ボタンを押して Google の画面で許可する
   - **Slack / GitHub** … 使う場合だけ
5. 止めるときは `Stop.cmd`、または窓を閉じる

API キーを入れた直後に判定とワーカーが動き始める。**起動し直す必要はない。**

## よくある詰まり

| 症状 | 原因 | 直し方 |
|---|---|---|
| アイコンを押しても何も起きない | ZIP のファイルがブロックされている | `Install.cmd` を実行し直す（ブロックを外す） |
| 「WindowsによってPCが保護されました」 | SmartScreen | 「詳細情報」→「実行」。配布元が自分だと分かっている場合のみ |
| カードが増えない。取り込みは動いている | Claude の API キーが未設定 | カンバン上部の警告から「ここで設定する」 |
| 起動直後に「接続の確認に失敗しました」 | 別の PC / 別のユーザーで作られた `phase5\data\secrets.dat` を持ってきた | そのファイルを削除して、画面から入れ直す（DPAPI は持ち主以外復号できない） |
| ポートが使われていて開かない | 8787 が別のアプリと衝突 | `config\app-config.json` の `startup.port` を変える |
| 画面が真っ白 | ブラウザのキャッシュ | 再読み込み。直らなければ `Stop.cmd` → もう一度起動 |

## 更新の配り方

フォルダを丸ごと置き換える。`phase1/data`・`phase2/data`・`phase5/data`（カードと資格情報）は
**残す**こと。消すと設定と履歴が消える。

## 消すとき

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -Uninstall
```

ショートカットだけが消える。データを消すにはフォルダごと削除する。
